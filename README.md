# JobTracker

A full-stack web application to track job applications during your job search. Stay organized, follow up on time, and never lose track of an opportunity again.

## Features
- Authentication (sign up, sign in, sign out)
- Add, edit and delete job applications
- Track status: Applied, Interview, Offer, Rejected
- Dashboard with real-time stats
- Filter applications by status
- Add notes and job links per application
- Data persists per user in a real database

## Technologies
- React
- JavaScript ES6+
- CSS3
- Vite
- Supabase (PostgreSQL + Auth)
